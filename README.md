# SC Tech — Prática de Git e GitHub

Laboratório acadêmico de **controle de versão e colaboração remota**, realizado na formação **SC TEC — Carreira Tech — Trilha Análise de Dados — Introdução ao Data Science**.

> Este repositório é intencionalmente pequeno: o objetivo das Aulas 05 e 06 era praticar o **fluxo Git/GitHub**, e não construir uma aplicação de produção. Todo o conteúdo publicado aqui é sintético e inofensivo.

## Objetivo

Demonstrar, em ambiente controlado, o ciclo mínimo de trabalho remoto com Git e GitHub:

1. autenticar uma conta GitHub existente;
2. configurar `remote origin`;
3. realizar o primeiro `push`;
4. clonar o repositório;
5. criar uma branch de exercício;
6. registrar um commit sintético;
7. publicar a branch remota;
8. abrir um Pull Request;
9. executar merge controlado;
10. validar a branch principal após o merge.

## Competências demonstradas

- versionamento distribuído com Git;
- branches e commits com finalidade explícita;
- sincronização local/remota;
- Pull Request como mecanismo de revisão e integração;
- merge e verificação pós-merge;
- separação entre ambiente de prática e projetos reais;
- cuidado com credenciais, tokens, dados pessoais e arquivos sensíveis.
