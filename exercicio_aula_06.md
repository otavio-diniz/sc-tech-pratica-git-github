# Exercício — Aula 06: branch, Pull Request e merge

Este arquivo registra a prática controlada de colaboração remota realizada no laboratório SC Tech.

## Sequência praticada

1. criar uma branch dedicada ao exercício;
2. realizar uma alteração sintética e verificável;
3. registrar um commit com finalidade clara;
4. publicar a branch no GitHub;
5. abrir um Pull Request para a branch principal;
6. revisar o conjunto de mudanças;
7. executar o merge de forma controlada;
8. confirmar o estado final da branch principal.

## O que o exercício demonstra

O foco não é a complexidade do conteúdo alterado, mas o **processo de versionamento**: separar trabalho em branch, manter histórico, revisar antes de integrar e confirmar o resultado após o merge.

## Limites

- material exclusivamente sintético e inofensivo;
- nenhuma credencial é registrada no repositório;
- nenhum projeto real é usado como ambiente de teste;
- a publicação atual é posterior ao exercício acadêmico original e tem finalidade de portfólio.
